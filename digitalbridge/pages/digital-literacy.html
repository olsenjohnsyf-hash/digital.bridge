Digital literacy for beginners

These lessons explain the parts of a computer, how files are organized, and how to move around the internet without treating every page as equally trustworthy.

What digital literacy means

A person who is digitally literate can use common technology and can also pause to ask whether information deserves trust. UNESCO's media and information literacy work supports people in engaging critically with information and navigating the online environment safely.

On DigitalBridge, that means learning the tool first, then learning the habit of checking what the tool shows you.

Computer hardware and software

Hardware is the physical machine. Software is the set of instructions that tells the hardware what to do.

Hardware examples

  • Monitor, laptop screen, or phone screen
  • Keyboard, mouse, and touchpad
  • Processor, memory, and storage inside the device
  • Printer, speakers, and USB drive

Software examples

  • The operating system
  • A web browser
  • A word processor or photo editor
  • The files you create, such as essays and photos

Operating system basics

The operating system is the main software that starts when you turn a computer on. Windows, macOS, ChromeOS, Android, iOS, and Linux distributions are examples. Names differ, but the jobs are similar.

  1. Sign in with your own account when the device asks for one.
  2. Use the desktop, home screen, or app list to open a program.
  3. Use settings to change Wi-Fi, sound, and display.
  4. Shut down or restart from the system menu instead of only holding the power button.
Beginner checkpoint. If you can open a program, find the settings, and shut down correctly, you are already using the operating system.

File and folder management

A file is a stored item with a name, such as history-notes.docx or family.jpg. A folder groups files. Good names save time later.

  • Create a folder for a subject, such as School or Receipts.
  • Save new work into that folder. Use Save As when you need a second copy.
  • Rename files so the name says what is inside.
  • Delete with care. Many systems move a file to Trash or Recycle Bin first, where it can still be restored.
  • Back up important school or family files to a second location you control.

Basic internet navigation

The internet is a worldwide network. A website is a set of pages on that network. The address bar shows where you are.

  • A URL is the address of a page, such as the address of a library or a government agency.
  • HTTPS means the connection is encrypted. Encryption protects the message while it travels. It does not prove the sender is honest.
  • The Back button returns to the previous page. A bookmark saves an address you want again.
  • Links can be words, buttons, or pictures. Read where a link claims to go before you open it.

Web browsers and search engines

A browser is the application that displays pages. Common browsers include Chrome, Firefox, Edge, and Safari. A search engine is a service, used inside the browser, that helps you find pages. Google, Bing, and DuckDuckGo are search engines.

  1. Open the browser.
  2. Click the address bar.
  3. Type a question or a known address, then press Enter.
  4. Read the result titles and site names before choosing one.
  5. Prefer a result from a known school, library, government agency, or established organization when the topic is health, money, or safety.

Responsible use of online information

Anyone can publish a web page. A careful reader asks four questions:

  1. Who wrote it, and does that person or organization have relevant knowledge?
  2. When was it published or updated?
  3. Why was it published: to teach, to sell, or to persuade?
  4. Where else does a reliable source say the same thing?

Copying someone else's words or pictures and presenting them as your own work is not responsible use. Quote briefly, say who created the work, and follow the license. The Ethics page explains how this website handles that duty.

A short practice guide

Try this once with a parent, teacher, or classmate:

  1. Name three pieces of hardware on the device in front of you.
  2. Open the file manager and create a folder called Practice.
  3. Open a browser and go to a website by typing an address you already know.
  4. Search for a topic from class and write down the author and date of one result.
  5. Check your understanding with the practice quiz.
