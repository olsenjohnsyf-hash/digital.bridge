## What the AI tool helped with

- Proposed the file structure and shared page layout.
- Drafted HTML lesson text, CSS, and the quiz script.
- Suggested original SVG illustrations.
- Checked a set of public URLs and kept sources that could be identified.

## What the AI tool did not do

- It did not replace the group's duty to read the pages and defend them.
- It did not create a database, accounts, or a login.
- It did not verify every future change the group might make after this draft.
- It is not a cited author of the educational facts. UNESCO, CISA, NIST, EPA, ITU, UNITAR, and the other organizations on the References page are the sources for those facts.
